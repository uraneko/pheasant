## Crates
- request
- respond 
- socket 
- message 

### Request
- request data type
- http11 request parsing
- request scrutiny (requires socket data fields)
- http2 request parsing

### Respond
- respond data type
- http11 response serialization
- http2 response serialization

### Socket
- http socket data type
- stream api: when a tcp stream is received, we wrap it in Stream<S> 
- contains servlets / resources + fallbacks

### Message
- uses the Stream<S> + Request + Respond apis to carry out http operations
enum Message<'a> {
    Read{
        stream: Stream<ReadUntil>,
        buf: &mut [u8],
    },
    Process {
        socket: SocketRef<'a>,
    },
    Write { 
        stream: Stream<Write>,
    },
}
